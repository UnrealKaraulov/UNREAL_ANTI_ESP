### Русская версия

#### Инструкция по установке:
1. Скомпилируйте исходный файл `anti_esp.sma`
2. Добавьте плагин в конфигурационный файл `plugins.ini`
3. Перезапустите игровой сервер
4. Загрузите звуковые файлы на FastDL сервер

#### Основные функции:
- Обфускация названий звуковых файлов
- Система генерации ложных звуков
- Контроль громкости на основе расстояния (Новейшая защита 2024)
- Сокрытие событий, связанных с оружием
