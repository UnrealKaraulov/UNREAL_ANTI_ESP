# 🚫 UNREAL ANTI‑ESP PLUGIN v3.42

Многоуровневая защита от Sound ESP и wallhack‑читов для игровых серверов CS 1.6 / HLDS на базе **AMX Mod X + ReAPI**.  
Плагин перехватывает и модифицирует игровые звуки, создаёт ложные аудиособытия, скрывает события оружия и использует дистанционное затухание громкости для дезориентации читов.

---

## 📋 Требования

- **AMX Mod X** 1.9+ (рекомендуется последняя сборка)
- **ReAPI** (≥ 5.24.3.0, для некоторых функций ≥ 5.26.3.24)
- **WHBlocker** (с отключённой встроенной ESP‑защитой)
- Модуль **FakeMeta**
- Модуль **XS**
- `<easy_cfg>` (идёт в архиве)
- Доступ на запись в `addons/amxmodx/configs/plugins/` и `sound/`
- FastDL для раздачи звуков клиентам

---

## 📦 Установка

1. **Скомпилировать плагин**
   - Поместите `anti_esp.sma` в `addons/amxmodx/scripting/`
   - Убедитесь, что в `scripting/include/` есть:
     - `reapi.inc`
     - `fakemeta.inc`
     - `xs.inc`
     - `easy_cfg.inc`
   - Скомпилируйте:
     ```bash
     amxxpc anti_esp.sma -o anti_esp.amxx
     ```
     Готовый `.amxx` поместите в `addons/amxmodx/plugins/`

2. **Подключить плагин**
   - В `addons/amxmodx/configs/plugins.ini` добавьте:
     ```
     anti_esp.amxx
     ```

3. **Настроить WHBlocker**
   - В его конфиге (`whblocker.ini`) отключите встроенную ESP‑защиту:
     ```
     esp = 0
     sndinvis = 0
     sndchan = 0
     sndfake = 0
     sndrange = 8192
     sndpickup = 1600
     sndshuff = 1.0
     sndmove = 0
     ```

4. **Перезапустить сервер**
   - При первом запуске плагин создаст:
     - `unreal_anti_esp.cfg.ini` в `configs/plugins/`
     - Папки и звуки в `sound/`
   - Скопируйте новые звуки на FastDL

## ⚙️ Конфигурация

Файл: `addons/amxmodx/configs/plugins/unreal_anti_esp.cfg.ini`

### [general]

| Параметр | По умолчанию | Описание |
|----------|--------------|----------|
| `fake_path` | `player/pl_step5.wav` | Путь к фейковому звуку (похож на оригинал) |
| `missing_path` | `player/pl_step0.wav` | Путь к несуществующему звуку для краша ESP |
| `send_missing_sound` | `true` | Отправка несуществующего звука |
| `enable_fake_sounds` | `1` | 0 — выкл., 1 — вокруг всех, 2 — вокруг игрока |
| `ent_classname` | `idyti_cmgrptft` | Имя фейковых сущностей |
| `repeat_channel_mode` | `false` | Повторное использование каналов |
| `more_random_mode` | `false` | Рандомизация громкости/затухания |
| `reinstall_with_new_sounds` | `false` | Полная переустановка с новыми звуками |
| `max_ents_for_sounds` | `14` | Лимит сущностей для фейк‑звуков |
| `crack_old_esp_box` | `true` | Ломает старые ESP |
| `volume_range_based` | `true` | Громкость по расстоянию |
| `volume_range_dist` | `64.0` | Дистанция для расчёта громкости |
| `cut_off_sound_dist` | `1500.0` | Обрезка звуков за пределом дистанции |
| `cut_off_sound_vol` | `0.001` | Обрезка тихих звуков |
| `replace_sound_for_all_ents` | `false` | Совместимость с другими плагинами (устарело) |
| `antiesp_for_bots` | `true` | Включение защиты для ботов |
| `hide_weapon_events` | `0` | 0 — выкл., 1 — эмуляция, 2 — полное скрытие |
| `USE_ORIGINAL_SOUND_PATHS` | `false` | Не менять пути звуков |
| `USE_ORIGINAL_ENTITY_AND_CHANNEL` | `false` | Не подменять сущности/каналы |
| `process_all_sounds` | `true` | Обрабатывать все звуки |
| `DEBUG_DUMP_ALL_SOUNDS` | `false` | Логировать все звуки (не включать!) |

## 🔑 Основные функции

- Обфускация имён звуковых файлов
- Генерация ложных звуков
- Подмена параметров звука и громкости (от дистанции)
- Сокрытие событий оружия
- Ломает старые ESP‑читы
- Поддержка ботов
- Автогенерация звуков при первом запуске

---

## ⚠️ Рекомендации

- Не используйте устаревшие анти‑ESP плагины вместе с этим
- Убедитесь, что другие плагины не создают рядом с игроком сущности, выдающие его позицию
- На слабых серверах проверяйте нагрузку и FPS после установки
- В секции `[sounds]` должно быть не менее **47** звуков для максимальной защиты
